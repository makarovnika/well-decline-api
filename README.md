# Well Decline API

Учебный сервис на FastAPI для прогноза падения дебита нефтяных скважин по кривым Арпса.
Итоговый проект курса «Инфраструктура и администрирование» (НИУ ВШЭ, 2026).

**Для кого:** инженер-разработчик или студент-нефтяник, которому нужно быстро оценить,
как будет падать дебит скважины, сколько она проработает до экономического предела
и сколько нефти добудет за это время (EUR, estimated ultimate recovery).

## Что умеет сервис

Модель Арпса описывает падение дебита тремя параметрами:
`qi` — начальный дебит (м³/сут), `di` — начальный темп падения (1/месяц),
`b` — показатель Арпса (0 — экспоненциальное, 0 < b < 1 — гиперболическое, 1 — гармоническое падение).

| Метод | Адрес | Что делает |
|---|---|---|
| GET | `/` | Приветствие и ссылка на документацию |
| GET | `/health` | Проверка работоспособности: `{"status": "ok"}` |
| GET | `/version` | Название, версия и автор сервиса |
| GET | `/wells?field=Северное` | Список скважин, фильтр по месторождению |
| GET | `/wells/{id}` | Одна скважина; 404, если её нет |
| POST | `/wells` | Добавить скважину (JSON: `name`, `field`, `qi`, `di`, `b`) |
| GET | `/wells/{id}/forecast?months=24` | Помесячный прогноз дебита и накопленной добычи |
| GET | `/wells/{id}/eur?q_limit=10` | Срок до экономического предела и EUR |
| GET | `/decline/rate?qi=100&di=0.08&b=0.5&t=12` | Калькулятор дебита и добычи без реестра |

Реестр скважин хранится в памяти процесса и содержит три учебные (вымышленные) скважины.
После перезапуска добавленные через POST скважины пропадают — база данных в проекте не используется.

## Установка

Нужен Python 3.12 или новее.

```bash
git clone https://github.com/makarovnika/well-decline-api.git
cd well-decline-api
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env    # при необходимости поправьте значения
```

## Запуск

Обычный запуск (без `--reload`):

```bash
python -m uvicorn app_final:app --host 127.0.0.1 --port 8000
```

Для разработки, с автоматическим перезапуском при правке кода:

```bash
python -m uvicorn app_final:app --reload
```

После запуска:

- сервис: http://127.0.0.1:8000
- интерактивная документация: http://127.0.0.1:8000/docs

## Переменные окружения

Значения читаются из окружения или из файла `.env` (пример — `.env.example`).
Настоящий `.env` в репозиторий не попадает.

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `APP_NAME` | `Well Decline API` | Название сервиса в `/`, `/version` и `/docs` |
| `APP_AUTHOR` | `Nikita Makarov` | Автор в `/version` |
| `LOG_LEVEL` | `INFO` | Уровень логов: `DEBUG`, `INFO`, `WARNING`, `ERROR` |
| `ECONOMIC_LIMIT` | `5` | Экономический предел дебита для `/wells/{id}/eur`, м³/сут |

Пример: `ECONOMIC_LIMIT=20 python -m uvicorn app_final:app` — и `/wells/1/eur` считает до 20 м³/сут.

## Тесты

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -v
```

Тесты проверяют `/health`, `/version`, фильтр и 404 по скважинам, прогноз, EUR, отклонение
неверных параметров (422), добавление скважины и сверяют аналитическую накопленную добычу
с численным интегралом дебита для всех трёх типов падения.

## CI

GitHub Actions (`.github/workflows/ci.yml`) на каждый push и pull request в `main`:

1. `test` — ставит зависимости и запускает `python -m pytest -v`;
2. `package` — только если тесты прошли, публикует artifact `well-decline-api`
   с файлами приложения (хранится 7 дней).

## Проверка и диагностика

```bash
curl http://127.0.0.1:8000/health      # {"status":"ok"}
curl http://127.0.0.1:8000/version     # {"name":"Well Decline API","version":"0.1.0",...}
curl "http://127.0.0.1:8000/wells/1/forecast?months=6"
```

**Где логи.** Сервис пишет логи в терминал, где запущен uvicorn: старт приложения,
каждый запрос (метод, путь, код ответа, время) и результаты расчётов. Чтобы сохранить их в файл:

```bash
python -m uvicorn app_final:app --port 8000 2>&1 | tee service.log
```

Пример строк лога:

```
INFO well_decline: Starting Well Decline API v0.1.0 (author: Nikita Makarov)
INFO well_decline: EUR for W-101 at q_limit=5.0: 86387 m3 in 106.9 months
WARNING well_decline: Well 42 not found
```

**Если что-то не работает:**

| Симптом | Что проверить |
|---|---|
| `No module named uvicorn` / `fastapi` | Активировано ли `.venv`; выполнен ли `pip install -r requirements.txt` |
| `Address already in use` | Порт 8000 занят: остановите прежний сервер (Ctrl+C) или запустите с `--port 8001` |
| `curl` не отвечает | Запущен ли сервер; совпадают ли адрес и порт; `lsof -i :8000` покажет процесс на порту |
| Ответ `422` | Параметр вне допустимых границ: `qi > 0`, `0 < di ≤ 1`, `0 ≤ b ≤ 1` — подробности в теле ответа |
| Ответ `404` на `/wells/{id}` | Скважины с таким id нет; список — `GET /wells` |
| Не меняется настройка из `.env` | Файл называется именно `.env` и лежит в корне проекта; сервис перезапущен |
